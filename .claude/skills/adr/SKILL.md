# Architecture Decision Record

1. If not decided yet: 2–3 real options with trade-offs for THIS project (cost, complexity, learning
   value, interview value), and a recommendation. Wait for her decision.
2. Once decided: create docs/decisions/NNNN-short-title.md (next number) with Status, Date, Context,
   Options considered, Decision, Consequences (+/−), Revisit when. Under ~40 lines, in her voice.
3. If it changes the stack or data model, update CLAUDE.md and docs/ARCHITECTURE.md.
